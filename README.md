#  Password Generator (Python)

##  Task Overview

This project is a simple command-line Password Generator built using Python.  
It generates strong and secure passwords based on user-defined length.

---

##  Objective

To create a secure password generator that demonstrates Python concepts such as:
- Random module usage
- String manipulation
- Loops and conditionals
- Function-based programming

---

##  Features

- Generates strong random passwords
- Includes:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Ensures password security by mixing characters
- User-defined password length

---

##  Tools & Technologies

- Python 3

---

##  How to Run

### Step 1:
Make sure Python is installed

### Step 2:
Open terminal or command prompt

### Step 3:
Run the program:

```bash
python randompass.py

---

##  Program Flow

* User enters desired password length
* Program checks if length is at least 4
* At least one character from each category is added:

  * lowercase
  * uppercase
  * digit
  * special character
* Remaining characters are randomly generated
* Final password is shuffled and displayed

---

##  Example Execution

```
Enter password length: 10
Generated Password: aB9@kL2!xQ
```

---

##  Validation Rule

* Minimum password length required is **4**
* If length is less than 4, program shows an error message
